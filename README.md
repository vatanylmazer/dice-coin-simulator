🎲 ChanceLab (Coin Flip & Dice Simulator)

A sleek, interactive probability and statistics simulator built with vanilla JavaScript, featuring coin flipping and dice rolling mechanics with live tracking.

🚀 Features
- Interactive Coin Flip simulation with real-time statistics (Heads/Tails counter).
- Dice rolling simulator utilizing unicode dice faces and history tracking.
- Smooth UI tab transitions and modern dark-mode aesthetic.

🛠️ Built With
- HTML5
- CSS3 (Flexbox, Modern UI Design)
- JavaScript (DOM Manipulation, Math Random Logic)

⚙️ Setup & Run
1. Clone this repository to your local machine.
2. Open `index.html` in your browser or run it via Live Server.
